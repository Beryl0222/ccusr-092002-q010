# 循环租用履约风控

管理数码与户外设备的验机、信用免押、物流交接、损伤争议和循环寿命。

`contracts/rental_asset.json` 保存公开的领域样例，用来约定外部数据的名称与层级；样例不含真实个人资料、业务凭据或生产连接信息。

执行 `npm run check` 可检查服务身份与资产载入，运行 `npm test` 可核对基础契约与全部实验规则。服务启动后，`/health` 返回项目标识。

## 租赁策略实验服务

针对"提前预授权 / 分层保障计划 / 按时归还奖励"三种免押策略做**可信的分组对比**，而不是全站改规则后看坏账。代码位于 `src/experiment/`：

| 模块 | 职责 |
| --- | --- |
| `assets.js` | 从 `rental_asset.json` 读取设备类别、成色、配件、所在仓与可租状态 |
| `eligibility.js` | 合规资格判定，只产出结构化原因码与质量标记 |
| `assignment.js` | 稳定哈希分组、用户/资产跨实验互斥、暴露区间（续租/调拨/停止） |
| `events.js` | 下单、取消、逾期、损伤争议、复租五类结果事件，按 `type+event_id` 幂等 |
| `metrics.js` | 指标口径版本注册；口径发布后不可变 |
| `stats.js` | Wilson 区间、Newcombe 风险差区间、ISO 周分层、SRM 卡方检验 |
| `reports.js` | 版本化报告、分层、隐私抑制、推广/回滚/继续观察建议 |
| `platform.js` | 门面，串联完整流程 |

### 设计原则（对应业务约束）

1. **先资格后分组**：资产必须 `inspection_passed` 且用户实名/风控/账龄合格才入组。分组由 `哈希(实验盐值 + 用户编号)` 决定，同一用户永远同臂，与仓库、成色、下单时间无关，可复现。
2. **互斥不污染**：同一用户、同一资产在暴露区间未结束时不能进入另一个实验；区间结束释放后可参与新实验。重复下单被拒绝而不是产生第二条暴露。
3. **暴露区间不可变**：续租只计次不换组；跨仓调拨写入仓库时间线不换组；策略中途停止后旧暴露继续归因，仅停止新入组；复租沿用首次分组。
4. **失败样本不删除**：每次入组尝试（含被拒绝的）都进入筛选日志。批量账号被拦截但计数可见；人工客服豁免**仍入组但单独打标**；验机数据缺失**不拒绝、单独分层**。
5. **事件幂等且允许迟到**：重复 `event_id` 返回 `duplicate` 不重复计数；事件载荷做字段白名单，自由文本 PII 不入库。迟到事件（在上份报告截止线之前发生、之后才汇入）触发**新版本报告**，旧报告原样保留。
6. **口径先行才能冻结**：分析人员必须先发布带版本的指标定义（`POST /metrics`），实验才能冻结，杜绝边看结果边改定义。
7. **ITT 归因**：所有指标按首次分组归因，取消、争议、续租都不改变分组，也不把失败样本偷偷剔臂。
8. **结论自带证据与不确定性**：每份报告附样本资格、逐类排除原因、质量标记、仓库/成色/类别/ISO 周/节假日/验机数据/客服豁免分层、每臂 Wilson 95% 区间和对对照组的风险差区间。
9. **SRM 失衡守卫**：报告对实际分流与预设权重做卡方检验，显著失衡时即使点估计有利也**禁止推广**（护栏指标显著受损时仍建议回滚）。
10. **运营隐私阈值**：`ops` 角色看不到任一策略臂样本量低于阈值（默认 30）的分层格数值，只看到维度与样本量；`analyst` 可见全量并带抑制标记。

建议规则：护栏（取消率、损伤争议率）或主指标（逾期率，坏账前置代理）显著劣化 → `rollback`；主指标显著优化且无护栏受损、无 SRM 报警 → `rollout`；区间跨越实际显著性边际 → `continue_observing`。**建议面向策略决策，不用于干预单笔租赁。**

### HTTP 接口

```
GET  /health
GET  /assets
POST /experiments
POST /experiments/{id}/enroll
POST /experiments/{id}/stop
POST /experiments/{id}/freeze
POST /experiments/{id}/reports          # body: {control_arm, holiday_ranges, role}
GET  /experiments/{id}/reports          # ?role=ops 触发隐私抑制
POST /metrics                            # 发布不可变指标口径
POST /events                             # 幂等结果事件（支持 {events:[...]} 批量）
POST /exposures/{id}/renew
POST /exposures/{id}/transfer            # {warehouse}
POST /exposures/{id}/close
```

角色通过 `role` 传入（演示用；生产应替换为鉴权中间件）。

### 本地运行

```bash
npm run check        # 身份与资产载入检查
npm test             # 40 项契约与实验规则测试
node src/service.js --port 8000
```
